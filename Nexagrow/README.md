# Nexa Grow Farms 🌿

A modern web presence for **Nexa Grow Farms**, an organic wellness brand focused on premium Moringa products — bringing nature's powerhouse to your daily routine.

---

## 📌 Project Overview

**Nexa Grow Farms** is committed to providing fresh organic produce and high-potency natural supplements, with a focus on premium Moringa powder. This website was created to:

* Showcase premium Moringa products and organic offerings
* Build brand credibility and online visibility
* Provide an easy shopping experience across all devices

---

## 🏗️ Component Architecture (Atomic Design)

The UI follows **Atomic Design** for clean, maintainable component structure:

| Tier | Location | Description |
|------|----------|-------------|
| **Atoms** | `src/components/atoms/` | Basic building blocks (Button, etc.) |
| **Molecules** | `src/components/molecules/` | Combinations of atoms (future) |
| **Organisms** | `src/components/organisms/` | Complex sections (Navbar, Hero, ProductExcellence) |

See `src/components/ARCHITECTURE.md` for full documentation.
